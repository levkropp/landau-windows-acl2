An irrational quantity can be surrounded by exact rational bounds. Once the enclosure is justified, a finite calculation can establish an inequality about that quantity without representing it exactly.

An interval is information about a value

The rational interval [L,U] says that the intended value lies between its endpoints. The ACL2 representation is a dotted pair, (L . U). That pair is data; the assertion that it encloses the intended value is a separate statement.

Full width is U−L. If we choose the midpoint as an approximation, half the width bounds its error. If we choose a lower endpoint instead, the safe allowance is the full width. Later sample constructors deliberately use lower endpoints, so we keep these notions separate.

Propagate bounds through arithmetic

[L₁,U₁]+[L₂,U₂]=[L₁+L₂,U₁+U₂]
[L₁,U₁]−[L₂,U₂]=[L₁−U₂,U₁−L₂]

For subtraction, the largest subtracted value gives the smallest result. Scaling by a negative number reverses endpoint order. For example, multiplying [1/3,2/3] by minus two gives [−4/3,−2/3].

Work backward from the requested error

If two input intervals have widths at most ε₁ and ε₂, their sum or difference has width at most ε₁+ε₂. Multiplication by a known scalar c multiplies the width by |c|.

Suppose a final sum needs width at most 1/100. One possible allocation is 1/200 to each of two inputs. If the first input is then amplified by ten, that earlier allocation must pay for the amplification. Precision is part of the construction, not an afterthought.

A positive lower endpoint is a certificate

If an enclosure is valid and L>0, its intended value is positive. A positive midpoint alone does not establish that: the interval [−1/10,3/10] still permits a negative value.

A strict margin protects the conclusion from uncertainty. To force a lower endpoint above a threshold, it is enough for the underlying value to exceed that threshold by more than the possible full-width loss.
