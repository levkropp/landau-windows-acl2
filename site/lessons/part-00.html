A proof can be a finite object even when its conclusion concerns infinitely many numbers. Induction is the first example we need: a base case and one reusable step can cover every natural number.

Start with a language

In the usual first-order language of Peano Arithmetic, the arithmetic symbols are zero, successor, addition, multiplication and equality. Variables and the logical symbols let us form statements. A variable ranges over natural numbers, including zero.

Write S(x) for the successor of x. The familiar numeral 3 abbreviates S(S(S(0))). This is a fact about the notation: the objects we intend to describe are still numbers. We have chosen a small language for naming them.

A term names a number. For example, x + S(y) is a term; at x=2, y=3 it names six. A formula makes a claim, such as x + S(y) = 6. Its truth can depend on the values assigned to its variables.

Arithmetic by recursive rules

x + 0 = x
x + S(y) = S(x + y)

The first rule handles zero. The second removes one successor from the right input and places it around the result. Multiplication has the parallel rules x·0=0 and x·S(y)=x·y+x. Three copies of a number become four copies by adding one more copy.

Order can be defined using addition: x≤y means there is a natural number z such that x+z=y. For 3≤7, the witness is four. This definition explains the words “less than or equal to.”

Build a square from odd layers

Let O(n) mean the sum of the first n positive odd numbers. The empty sum is zero. Adding the next odd number gives

O(0)=0
O(n+1)=O(n)+2n+1.

The square picture explains why that recurrence is useful. Extending an n×n square to an (n+1)×(n+1) square adds a border of 2n+1 cells.

Now state the induction argument

The claim is O(n)=n², where O(n) is the sum just defined. At zero, both sides are zero. Suppose O(n)=n². The recurrence gives O(n+1)=n²+2n+1=(n+1)². Induction turns those two arguments into the statement for every natural number.

Only now do we need the placeholder letter P: “if P(0) and every P(n) implies P(S(n)), then every P(n).” In first-order Peano Arithmetic this is an axiom scheme: each formula supplies an instance. It is not a variable ranging over arbitrary sets.

Try the step yourself

Assume the first five odd numbers sum to 25. Find the sixth odd number and use the recurrence to obtain the next square. Then explain why checking the first six cases alone would not establish the general theorem.

Show the reasoning

The next odd number is 2·5+1=11, so 25+11=36=6². The induction step works for an arbitrary natural number; a finite list of successful checks does not supply that general implication.
