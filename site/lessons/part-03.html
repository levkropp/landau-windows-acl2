A finite scan can return a successful entry only if one is present. This lesson connects a continuous-looking peak to a stored rational interval with a positive lower endpoint.

Start with the actual scan

A sample is an enclosure [L,U]. The scan tests whether L is strictly above a threshold, then either returns the current index and interval or continues through the remaining list. It returns the first passing entry.

{{source:video/teaching-part03.lisp:defun:lw-first-above}}

A returned index identifies a list position. A grid maps that position to an address. A proof that an address is rational and inside a window is a different result from a proof that its interval encloses the intended function value.

Cover the point before transporting its margin

Suppose the grid covers the region: every relevant point is within distance h of a sampled address. Also suppose a rate bound controls how fast the function can fall:

F(a) ≥ F(p) − L|a−p|.

At a nearby address the value is therefore at least F(p)−Lh. If its enclosure has full width at most w, its lower endpoint is at least another w below that. Thus the strict condition F(p)>threshold+Lh+w forces a passing sample.

Follow one example all the way through

Use the teaching function F(x)=1−4|x−7/16| on [0,1]. Its peak is one, its rate bound is four, and the grid has spacing 1/8. Give each sample an enclosure of full width 1/4, centered on its exact teaching value.

The sufficient margin test is 1>4·(1/8)+1/4=3/4. The first passing index is two, with address 1/4 and enclosure [1/8,3/8]. It need not be the address closest to the peak.

Termination, soundness and success are distinct

The finite scan terminates because it consumes a finite list. If it returns an entry and the enclosures are correct, that entry certifies a value above the threshold. To prove that it returns an entry at all, the margin, coverage and rate hypotheses must be supplied.

The margin inequality is sufficient, not necessary. A coarse grid can happen to hit a good point even when this particular sufficient test fails. Conversely, valid enclosures cannot reveal a peak that an inadequate grid misses entirely.

Remove one of the guarantees

Set the demo to one grid subdivision. What happens? Then use two subdivisions. Does success require the sufficient margin test to pass in this example?

Show the reasoning

One subdivision samples only zero and one, where the teaching function is negative. Two subdivisions add one half, close enough to this particular peak to pass the scan. The conservative bound 1>4/N+w still fails at N=2, demonstrating that it is not necessary.
